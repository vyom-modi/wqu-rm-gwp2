# MScFE 660 Risk Management, Group Work Project 2 (Group 18596)

Hidden Markov regimes and a Bayesian network of crude oil prices, continuing GWP1.

- `GWP2_Notebook.ipynb`: the Colab notebook (seed 18596). It downloads the two data files below from this repository, so it can be opened in Colab and run with Runtime > Run all.
- `monthly_sterilized.csv`: the sterilized monthly panel produced in GWP1 (41 series, January 2005 to July 2026, built from FRED, EIA, Yahoo Finance and the Caldara and Iacoviello GPR index).
- `steo_world_block.csv`: the EIA Short-Term Energy Outlook world balance block from GWP1 (2022 onward).
